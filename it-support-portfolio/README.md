## 📂 Estructura del Repositorio

* **`01-troubleshooting/`** ➡️ Metodologías de resolución de problemas, tickets simulados y solución de errores en hardware/software.
* **`02-redes-y-comandos/`** ➡️ Comandos esenciales de red (`ping`, `traceroute`, `ipconfig`, etc.) y chuletas (*cheatsheets*).
* **`03-sistemas-operativos/`** ➡️ Administración de sistemas en Windows y Linux, gestión de usuarios y uso de máquinas virtuales.
* **`04-ciberseguridad/`** ➡️ Buenas prácticas de seguridad, autenticación multifactor y prevención de phishing.
